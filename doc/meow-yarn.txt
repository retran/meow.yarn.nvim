MEOW.YARN.NVIM				*meow.yarn* *meow-yarn*

A purr-fectly simple way to visualize LSP hierarchies in Neovim.

Ever feel like you're unraveling a tangled ball of yarn when navigating your
codebase? `meow.yarn.nvim` is here to help. It provides a simple, beautiful,
and interactive way to explore LSP hierarchies without the usual clutter.
Forget getting lost in endless definitions and references; `meow.yarn.nvim`
visualizes type and call hierarchies in a clean, intuitive tree view.

INTRODUCTION					*meow-yarn-introduction*

`meow.yarn.nvim` is a Neovim plugin that provides a simple, beautiful, and
interactive way to explore LSP hierarchies. It allows you to visualize type
and call hierarchies in a clean, intuitive tree view, helping you to
untangle your code's relationships.

==============================================================================
KEY FEATURES					*meow-yarn-features*

- *Clean, Interactive Tree*: Shows hierarchies in a straightforward,
  expandable list.
- *Type & Call Hierarchies*: Explore both supertypes/subtypes and
  callers/callees of functions.
- *Live Preview*: Instantly see the relevant code for any item you select
  in the tree.
- *Jump to Definition*: Press Enter on any item to go directly to its
  location in the code.
- *Keep Open After Jump*: Optionally stay in the hierarchy window after
  jumping to a symbol (`keep_open_on_jump = true`).
- *Explore Deeper*: Pick any symbol in the tree and make it the new starting
  point for exploration, or switch directions (e.g., from callers to
  callees) on the fly.
- *Navigation Breadcrumbs*: A history trail at the top of the tree window
  tracks where you navigated. Press `<BS>` to step back.
- *Re-open Last Session*: `:MeowYarn last` re-opens the last hierarchy
  exactly as it was (same symbol, strategy and direction).
- *Search / Filter*: Press `/` to filter the visible nodes by name.
  Non-matching nodes are dimmed; the active query is shown in the border.
- *Copy Path to Clipboard*: Press `y` to yank the `file:line` of the
  selected node to both the `+` and `"` registers.
- *Node Position Indicator*: Current row / total visible nodes shown in the
  top-right border corner, updated as you move.
- *Expand / Collapse All*: Press `zO` / `zC` to expand or collapse every
  fetched node at once.
- *Horizontal Layout*: Set `window.layout = "horizontal"` to place the
  preview pane to the right of the tree instead of below it.
- *Custom Node Renderer*: Supply a `render_node` function in your config to
  fully control how each tree node is displayed.
- *Fast & Non-Blocking*: Fully asynchronous so it won't freeze your Neovim.
- *Built on Solid Foundations*: Powered by Neovim's native LSP and
  `nui.nvim`.

==============================================================================
PREREQUISITES				*meow-yarn-prerequisites*

Required:
- Neovim: >= 0.8.0 (0.10+ recommended)
- LSP Client: An active LSP server that supports `typeHierarchyProvider` or
  `callHierarchyProvider`.
- Dependencies: `nui.nvim`

INSTALLATION				*meow-yarn-installation*

Install `meow.yarn.nvim` using your favorite plugin manager.

lazy.nvim:
>
	{
	    "retran/meow.yarn.nvim",
	    dependencies = { "MunifTanjim/nui.nvim" },
	    config = function()
	        require("meow.yarn").setup({
	            -- Your custom configuration goes here
	        })
	    end,
	}
<
packer.nvim:
>
	use {
	    "retran/meow.yarn.nvim",
	    requires = { "MunifTanjim/nui.nvim" },
	    config = function()
	        require("meow.yarn").setup({})
	    end,
	}
<
rocks.nvim:
>
	:Rocks install meow.yarn.nvim
<
The dependency (`nui.nvim`) will be automatically installed and managed.
Then add to your Neovim configuration:
>
	require("meow.yarn").setup({
	    -- Your custom configuration goes here
	})
<

QUICK START				*meow-yarn-quick-start*

The plugin provides the |:MeowYarn| command to open hierarchy views.

- View Type Hierarchy (Supertypes): >
	:MeowYarn type super
<
- View Type Hierarchy (Subtypes): >
	:MeowYarn type sub
<
- View Call Hierarchy (Callers): >
	:MeowYarn call callers
<
- View Call Hierarchy (Callees): >
	:MeowYarn call callees
<
- Re-open the last hierarchy: >
	:MeowYarn last
<

CONFIGURATION				*meow-yarn-configuration*

You can customize the plugin by passing a configuration table to the `setup`
function. Here are the defaults:
>
	require("meow.yarn").setup({
	    window = {
	        width = 0.8,
	        height = 0.85,
	        border = "rounded",
	        preview_height_ratio = 0.35,
	        -- "vertical": tree above, preview below (default)
	        -- "horizontal": tree left, preview right
	        layout = "vertical",
	    },
	    icons = {
	        loading = "",
	        placeholder = "",
	        animation_frames = { "⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏" },
	    },
	    mappings = {
	        jump = "<CR>",
	        toggle = "<Tab>",
	        expand = "l",
	        expand_alt = "<Right>",
	        collapse = "h",
	        collapse_alt = "<Left>",
	        show_super_hierarchy = "K",
	        show_sub_hierarchy = "J",
	        quit = "q",
	        -- Navigate back through breadcrumb history.
	        -- Set to nil to disable the keymap entirely.
	        breadcrumb_back = "<BS>",
	        -- Yank file:line of the selected node to clipboard.
	        -- Set to nil to disable.
	        yank_path = "y",
	        -- Expand / collapse all fetched nodes at once.
	        -- Set to nil to disable.
	        expand_all = "zO",
	        collapse_all = "zC",
	        -- Open filter prompt. Set to nil to disable.
	        filter = "/",
	    },
	    -- When true, the hierarchy window stays open after pressing <CR>
	    -- to jump to a symbol. Default: false (window closes on jump).
	    keep_open_on_jump = false,
	    expand_depth = 3,
	    preview_context_lines = 10,
	    animation_speed = 100,
	    hierarchies = {
	        type_hierarchy = {
	            icons = {
	                class = "󰌗",
	                struct = "󰙅",
	                interface = "󰌆",
	                default = "",
	            },
	        },
	        call_hierarchy = {
	            icons = {
	                method = "󰆧",
	                func = "󰊕",
	                variable = "",
	                default = "",
	            },
	        },
	    },

	    -- Optional: override how each tree node is rendered.
	    -- When set, this function is called for every node instead of the
	    -- built-in renderer. Return a plain string to use as the full line
	    -- text, or return nil to fall back to the default rendering.
	    --
	    -- The argument is a meow.yarn.NodeInfo table with these fields:
	    --   name         string       Symbol name
	    --   kind         string       Kind string (e.g. "Class", "Function")
	    --   icon         string       Resolved icon for this node
	    --   file         string|nil   Shortened file path, or nil
	    --   line         number|nil   1-based line number, or nil
	    --   detail       string|nil   LSP detail string, or nil
	    --   depth        number       Tree depth (root = 1)
	    --   is_loading   boolean      True while children are being fetched
	    --   is_placeholder boolean    True for the initial loading placeholder
	    --   direction    string|nil   Direction key (e.g. "supertypes", "callers")
	    --
	    -- render_node = function(node_info)
	    --     return string.format("%s %s", node_info.icon, node_info.name)
	    -- end,
	})
<

BREADCRUMBS				*meow-yarn-breadcrumbs*

Every time you navigate to a new root by pressing `K` or `J`, the plugin
records the previous root in a history list. The current path is displayed as
a breadcrumb trail in the tree window title:

	 [Animal] > [Dog] > [Poodle] 

Pressing `<BS>` (the default `mappings.breadcrumb_back` key) navigates back
one step, restoring the previous root item and direction.

*Note*: Breadcrumb display uses nui.nvim's border text API and works on all
supported Neovim versions (>= 0.8.0). No version upgrade is required.

To disable breadcrumb-back navigation entirely (e.g. to reclaim `<BS>` for
another use), set the mapping to `nil` in your config:
>
	require("meow.yarn").setup({
	    mappings = { breadcrumb_back = nil },
	})
<

==============================================================================
SEARCH / FILTER				*meow-yarn-filter*

Press `/` (default `mappings.filter`) inside the hierarchy window to open a
filter prompt. Type a query and press `<Enter>` to apply it.

- Nodes whose name contains the query (case-insensitive substring match) are
  shown normally.
- Non-matching nodes are dimmed using the `Comment` highlight group. They
  remain visible so the tree structure is preserved.
- The active query is shown in the bottom-left border: ` /query/ `
- Clear the filter by pressing `/` again and submitting an empty string.
- The filter is automatically cleared whenever you navigate to a new root
  (via `K`, `J`, or `<BS>`).

To disable the filter keymap, set it to `nil`:
>
	require("meow.yarn").setup({
	    mappings = { filter = nil },
	})
<

CUSTOM NODE RENDERER			*meow-yarn-render-node*

The `render_node` configuration option lets you fully control how each node
in the hierarchy tree is displayed.

When set, the function receives a |meow-yarn-nodeinfo| table for every node
and must return either a plain string (the full line text) or `nil` to fall
back to the built-in rendering.

Example — show only icon and name: >
	require("meow.yarn").setup({
	    render_node = function(node)
	        return string.format("%s %s", node.icon, node.name)
	    end,
	})
<

Example — compact format with file and line: >
	require("meow.yarn").setup({
	    render_node = function(node)
	        local loc = ""
	        if node.file then
	            loc = string.format("  %s", node.file)
	            if node.line then loc = loc .. ":" .. node.line end
	        end
	        return string.format("%s %s%s", node.icon, node.name, loc)
	    end,
	})
<

Note: the custom renderer replaces the entire line content — indentation,
expand arrows, and highlight groups are all your responsibility. The function
is called even for loading and placeholder nodes; check `node.is_loading`
and `node.is_placeholder` as needed.

						*meow-yarn-nodeinfo*
The `node_info` table passed to `render_node` has these fields:

	`name`           string       Symbol name.
	`kind`           string       Symbol kind (e.g. "Class", "Function").
	`icon`           string       Resolved icon string for this node.
	`file`           string|nil   Shortened file path, or nil.
	`line`           number|nil   1-based line number, or nil.
	`detail`         string|nil   LSP detail string, or nil.
	`depth`          number       Tree depth (root = 1).
	`is_loading`     boolean      True while children are being fetched.
	`is_placeholder` boolean      True for the initial loading placeholder.
	`direction`      string|nil   Hierarchy direction key.
<

MAPPINGS					*meow-yarn-mappings*

You can map the commands for easier access.

Example Lua Keymaps:
>
	-- Using <Plug> mappings
	vim.keymap.set("n", "<leader>yt", "<Plug>(MeowYarnTypeSuper)", { desc = "Yarn: Type Supertypes" })
	vim.keymap.set("n", "<leader>yT", "<Plug>(MeowYarnTypeSub)",   { desc = "Yarn: Type Subtypes" })
	vim.keymap.set("n", "<leader>yc", "<Plug>(MeowYarnCallCallers)", { desc = "Yarn: Call Callers" })
	vim.keymap.set("n", "<leader>yC", "<Plug>(MeowYarnCallCallees)", { desc = "Yarn: Call Callees" })
	vim.keymap.set("n", "<leader>yl", "<Plug>(MeowYarnLast)",      { desc = "Yarn: Re-open last" })

	-- Or using Lua API
	vim.keymap.set("n", "<leader>yt", function()
	    require("meow.yarn").open_tree("type_hierarchy", "supertypes")
	end, { desc = "Yarn: Type Hierarchy (Super)" })
<

------------------------------------------------------------------------------
IN-WINDOW MAPPINGS			*meow-yarn-in-window-mappings*

Inside the hierarchy view, the following default keymappings are available:

|Key|		|Action|
|<CR>|		Jump to the location of the selected item (`mappings.jump`).
|<Tab>|		Toggle expand/collapse for the selected node (`mappings.toggle`).
|`l` or `<Right>`|	Expand the selected node (`mappings.expand`, `mappings.expand_alt`).
|`h` or `<Left>`|	Collapse the selected node (`mappings.collapse`, `mappings.collapse_alt`).
|`zO`|		Expand all fetched nodes (`mappings.expand_all`).
|`zC`|		Collapse all nodes (`mappings.collapse_all`).
|`/`|		Open filter prompt (`mappings.filter`).
|`y`|		Yank `file:line` of the selected node to clipboard (`mappings.yank_path`).
|`K` / `J`|	Open new hierarchy from selected item (K=super/callers, J=sub/callees).
|`<BS>`|	Navigate back one step in the breadcrumb history (`mappings.breadcrumb_back`).
|`q`|		Quit the hierarchy view (`mappings.quit`).

==============================================================================
COMMANDS					*meow-yarn-commands*

:MeowYarn {hierarchy_type} {direction}
			Opens the hierarchy view.

			{hierarchy_type}: `type`, `call`, or `last`
			{direction}:
			- for `type`: `super` or `sub`
			- for `call`: `callers` or `callees`
			- `last`: re-opens the previous hierarchy session
			  (no direction argument needed)
